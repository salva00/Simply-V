# SoC Simulation

Dual-backend simulation of the same RTL (filelist-swap HAL, see `sim_manifest.md`):

1. **Verilator** (open source) — the `xlnx_*` IPs are resolved by open shims in `models/`.
2. **xsim** (Vivado built-in) — the `xlnx_*` IPs are resolved by the vendor sim-models.

## Usage

### Smoke (no firmware required)

    source settings.sh embedded
    make -C hw/xilinx sim BACKEND=verilator TEST=smoke
    make -C hw/xilinx sim BACKEND=xsim      TEST=smoke   # requires Vivado

### Embedded hello_world ([EMB] PASS)

Prerequisites:
- `hello_world.hex` must be built first: `make -C sw/SoC/examples/hello_world` (produces `bin/hello_world.hex`).
- xsim only: run `make -C hw/xilinx sim_compile_simlib` once to build the Vivado IP simulation libraries (~24 min, result cached in `sim/build/simlib/`).

    source settings.sh embedded
    make -C hw/xilinx sim BACKEND=verilator TEST=embedded
    make -C hw/xilinx sim BACKEND=xsim      TEST=embedded   # requires Vivado + simlib

Sim artifacts generated by the config flow live in `generated/` (gitignored):
`make -C config config_sim` regenerates them (`sim_defines.svh`, `sim_addrmap_pkg.sv`,
`verilator_embedded.f`, `siminc/`).

Local CI: `bash hw/xilinx/sim/ci/compile_both.sh`.
